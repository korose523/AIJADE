# @proj-aijade/server-sdk-shared

Shared event contracts and types for AIJADE server SDK consumers and server-side handlers.

## Usage

```shell
ni @proj-aijade/server-sdk-shared -D
pnpm i @proj-aijade/server-sdk-shared -D
```

```typescript
import type { WireMessage } from '@proj-aijade/server-sdk-shared'

import { newMessages, pullMessages, sendMessages } from '@proj-aijade/server-sdk-shared'
```
