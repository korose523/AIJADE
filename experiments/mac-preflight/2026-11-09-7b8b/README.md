# AIJADE Mac 7B/8B 容量与速度预检实测记录

日期：2026-11-09（Asia/Seoul）。本轮按作者“先完成 7B/8B 容量与速度预检”的请求执行。原始输出位于 `experiments/mac-preflight/2026-11-09-7b8b/`，初测与 `admitted-repeat/` 复测并列。以下数据由 `analysis.json` 读取生成，完整数值、原始响应及逐秒监测均保留。正式 P2-A/B/R 主运行、Mac 长时间资格和第 7 章仍各自验收。

## 1. 本轮结论及其范围

在原冻结参数下，两模型在准入后复测中各完成 10/10 个固定请求。首轮 Qwen 仅完成 READY：在首次生成时，交换相对该模型起点增长超过 2 GiB 持续 30 秒而按方案停止；这条不利结果保留为 1/10 完成、1 次停止、8 次未尝试。Llama 初测完成 10/10。不能把后续完成改写为首次条件也通过。

复测前在模型卸载状态监测 60 秒，要求每次采样至少 7 GiB 可用内存，交换相对准入起点的增长不超过 256 MiB。提示、模型、量化、上下文、输出上限和停止阈值均未降低；未关闭其他应用、清理 OS 缓存或迁移权重。准入是开发执行条件，未作有无准入的随机比较，不能归因其效果。

本次关闭的是“这些模型、这些固定请求的可执行性、格式及条件用时”这一开发缺口。4096 是实际分配的上下文和配置的输出上限；本次并非 4096-token 输入与 4096-token 输出的极限压力测试。短时未触发停止条件不能证明持续稳定、全程确定性、一般吞吐量或更大模型的可行性。

墙钟含提示处理等开销；输入/输出 token 直接读取 API 的 `prompt_eval_count` / `eval_count`，未把字符长度当作独立分词计数。生成速率仅用服务端 `eval_count/eval_duration` 计算，READY 的两 token 速率不作为代表速度。每模型只有一个首次生成类请求和一个构造重试，未估计一般速度的置信区间或上界。原始响应的截断、空回复与错误分别记录，没有补成零 token 成功。

复测中 Qwen 与 Llama 的五个固定合成案例分别有 5/5 与 5/5 个符合既有 PASS/FAIL 前缀语法；验证请求全体分别为 7/7 与 7/7。C# 既有 `ReadVerdict` 对所有已测验证回复独立重判格式，与监测器一致。格式合规不等于判定正确，未用正确率挑选模型或调整提示。

另作事后的逐字核对：两轮都完成的 11 个请求中，11 个回复正文相同（Qwen 仅 READY 可配对，Llama 为整组请求）；完整响应 JSON 的计时字段不作文本相等标准。这只是开发样本的探索性检查，不是正式运行器前五 trial、五遍卸载后检查，也不能据此关闭全程确定性缺口。

## 5. 按调用类别核算后续设备时间

| 原控制 | 首次生成 | 重试生成 | 验证调用 | 主运行条件 API 小时 | 加 30% 余量小时 | 五遍前五试验确定性检查小时 |
|---|---|---|---|---|---|---|
| Llama 8B / A | 1440 | 79 | 770 | 25.52 | 33.17 | 21.80 |
| Qwen 7B / A | 1440 | 162 | 852 | 27.35 | 35.55 | 22.47 |
| Qwen 7B / B | 1440 | 60 | 750 | 25.00 | 32.50 | 20.63 |

公式为一次卸载后 READY + 首次生成数 × 对应实测墙钟 + 重试数 × 对应实测墙钟 + 验证调用数 × 对应模板墙钟。五遍确定性另按每组前五次 trial 的真实调用数计算，每遍包含 READY。主运行三组合计 77.86 小时，确定性检查合计 64.89 小时；两者加 30% 假定恢复余量约 185.58 设备小时。

这是条件情景，不是工期承诺、置信区间或最坏情况上界。新回复长度、重试和验证数量可能变化；字符最长不等于 token 或运行时间最长。尚未计入沙箱/持久化、模型切换、24 小时负载与 7 天观察、P2-A 参考解/难度/精度和主运行、P2-B 更大模型或独立审阅等待。初测 Qwen 缺少未删失的生成类用时，故其初测预算明确为不可估计，不用复测悄悄填补。

仅上述 185.58 小时已相当于约 7.73 个连续占用日；它是设备日，不是作者人日。若正式 Mac 标准仍采用先 24 小时负载再 7 天观察，按这一假定情景顺序安排的日历负荷约 15.73 天，且不含上述未计事项，观察期允许的其他工作另按正式标准。因而不能再按原 GPU 的分钟级负荷宣称 12/02–12/20 窗口宽裕；应在 11 月先固定资格和设备预约，12/20 检查实际回执、剩余调用量与 P2-A/B 可用窗口，容量或时长不满足时明确缩小尚未测量的主张，不以减少失败记录或更换较小模型冒充完成。
