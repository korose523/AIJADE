# 实际提示观察器的工程资格检查

本轮起点为 `c1ac116ce92adc5696bd2019b769f05d7229b912`。先记录检查范围，再实现测试侧观察器和测量入口选择。范围是新共享运行时下的记忆提示观察装置资格，不是 P3-E 的正式语料运行，也不改写历史 P3-E 的结果。

旧驱动用客户端规则算出预计的前五条，再检查完整文本块是否出现在捕获的请求中；历史归档中的提示不匹配数为零。新运行时可能截断或省略上下文，因此预计条目数不等于实际完整出现的条目数。新观察器只从实际捕获请求中确认可辨识的完整前缀条目，并区分截断、不出现、未捕获及无法唯一归属。部分文字不算一条完整记忆，重复内容或标记冲突不强行分配来源 ID。

检查使用合成记忆、实际应用 API／数据库及本地聊天响应替身，限定为以下边界：旧直接入口兼容、共享入口短文本、默认长度上限下的截断、记忆开关关闭、记忆请求失败、前置模块耗尽总预算、调用方取消，以及来源内容有歧义时拒绝认定。没有语言模型、嵌入模型或真实用户调用，也没有 LoCoMo 新样本或新的 recall 估计。

后续完整研究必须显式选择测量入口，记录默认长度策略、源码／二进制身份和原始捕获。共享库中的 memory-only 入口不能称为完整 Web／QQ、多轮聊天或主动消息测量。本轮只验证装置；完整语料、嵌入条件及汇总分析另按版本固定方案执行，原正式研究门槛保留。

实际结果见 `receipt.json`、`capture-check.json` 和 `synthetic/`。默认共享入口的短文本夹具完整出现五条；长文本夹具预计五条、完整出现两条，第三条只有部分文字；旧直接入口的相同长文本完整出现五条。记忆关闭、接口返回 503、前置模块耗尽预算时均无完整记忆块，聊天仍完成。取消夹具虽捕获请求，但只有用户消息入库，没有助手回复。这是七个合成边界，不是语料样本量或模型质量估计。

Release 编译修正一处测试断言的 CA1861 静态检查后通过，原失败日志保留。定向 20 通过、1 项完整语料运行按条件跳过；UTC 全量单元／集成 575 通过、15 跳过、0 失败（590 项）。缺失捕获、重复内容／ID、保留标记冲突和不能解释的块另有拒绝归属断言。853 个既有源码、配置及实验文件指纹不变，9,878 项论文事实、P3 数值占位符及表格行不变；稿件十二类守卫通过。本轮没有重跑浏览器或真实平台／模型用例。

本机测试可在启动开发数据库后，以 `AIJADE_TEST_DATABASE_URL` 配置数据库，运行 `dotnet test tests/Aijade.Tests/Aijade.Tests.csproj -c Release --filter FullyQualifiedName~ProductPromptObservationTests`。设置 `AIJADE_PROMPT_QUALIFICATION_DIR` 到新的空目录可保留合成捕获；已有同名文件会拒绝覆盖。不要设置完整研究的语料环境变量来运行这组资格测试。

v2 完整语料驱动本轮只编译，未执行其语料循环或汇总。将来须显式设 `AIJADE_P3E_ENTRY=legacy-direct` 或 `shared-memory-only`；其输出为 `product-path-v2-{entry}-{condition}.json`，缺失捕获或无法辨识时的观测字段为 `null`。原 v1 分析器仍只用于原归档，不能直接接收 v2。复现历史结果须检出对应归档提交，不把新仪器冒作原驱动。完整文本可见性不证明模型使用了它，也不独立证明来源身份；ID 关联仍以提供者的预计顺序及唯一文本为条件。
