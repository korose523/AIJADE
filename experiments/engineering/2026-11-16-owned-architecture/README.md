# 独立架构工程核验

实现提交为 `d7a33017bd0df82752ce5c52fd637e7909b591bd`。本目录记录产品重构的工程结果，不更换 P1/P2/P3 或第七章的测量源版本，也不重跑、扩充或重新授予留出资格。

本轮将原产品外部工作台代理替换为本库持久化虚拟场景，移除机器人宿主的外部渲染器装配，并实现本库 loopback 语音服务。命令与回执固定到同一账户和角色；重复请求返回原回执，修订冲突及不支持的动作不会产生部分状态写入。可选场景不可用时，文字回复与独立语音链继续工作。所有源码项目、功能入口及实现状态见 [功能目录](../../../docs/FUNCTIONS.md)。

Linux CI 的 690 项测试通过、31 项跳过；其浏览器测试默认未启用，38 项为跳过。Mac 上另行显式启用真实 Chromium，9 项网页/签名 QQ 协议场景通过，覆盖角色、地点时区、关系、收藏、生活设定、照片提示、主动消息、提醒及交付记录。模型上游为受控替身，QQ 事件由测试签名，不据此声称真实平台账号已上线。原生场景的持久性、账户/角色隔离、切换后的重放、并发修订、原子拒绝及超时边界由服务端和客户端测试另行检查。

本地服务的 12 项标准库测试通过。另通过真实 HTTP 合成得到 135,086 字节的系统语音 WAV，并使用已有 tiny 权重识别。回执保留实际识别文本中的误差；没有人工准确率结论。系统音色未经本项目训练，`emotionApplied=false`；音素对齐和歌声明确未实现。服务源码及 WAV 哈希见 [机器回执](receipt.json)。

架构守卫确认 15 个源码项目、28 个内部项目引用与 69 个功能族，9 个负控制均被拒绝。44 个已有源码功能族、19 个配置入口和 6 个待实现族按代码粒度分类，不能换算成整体产品完成率。标准库、驱动、协议和可配置模型服务保留；文献与历史来源也保留。`MosaicStage` 旧类型名、旧设置字段及冻结研究适配器属于兼容与溯源边界，不再装配为当前产品运行依赖。

论文研究版本仍固定在 `f90f04110f46fb17a2a43a777ed5d4e68a361902` 及其既有执行身份。当前产品、逻辑场景状态、系统语音、模型输出和独立外部观测分别记录；没有新增研究案例、独立人工核读或期刊接收结论。
