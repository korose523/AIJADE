# 情感陪伴功能核查与补全（2026-11-09）

作者本轮确定：AIJADE 以情感陪伴为主、当前优先完成；MOSAIC 保持连接组研究及非研究线具身智能，两者可借鉴。此前“AIJADE 产品只维护”已由 ADR-004 取代。本轮改动均在 AIJADE；没有启动模型训练、真实 QQ 消息、研究主运行，也没有修改 MOSAIC 工作区。

| 唱歌 | 无独立歌曲交付 | 新增带来源许可的歌声曲库、精确曲目查找、聊天音频、QQ record 发送；未知歌曲说明未练好。录音优先；没有匹配录音时可调用已配置的本地歌声服务，返回真实 WAV 后才交付。其他尚不支持音频的机器人渠道明确引导到 Web/QQ |
| 本地专属音色训练 | 本机语音服务可接入，未见本任务授权数据 | 尚未训练。需要本人或获授权的语音/歌声样本、对应文本/歌词、模型/服务路径。不能把数据入口或测试音频写成专属模型训练完成 |

## 使用入口

1. 登录 Web，在侧栏进入“陪伴生活”（Companion life）。保存虚拟住处、固定外貌、兴趣、音乐偏好、虚拟朋友和发型；角色可在既有“角色”页设置。收藏跟随账户与当前角色。
2. 查询城市后自行选择候选，才打开真实天气。Open-Meteo 是模型估算的当前天气，不是角色亲眼观察或设备定位。未配置、超时或失效时明确不可用。
3. 自然节奏和主动开口均可单独打开；原默认关闭设置保持。Web 的分钟循环依赖页面打开；机器人宿主可独立运行。
4. 收藏表情、服装或本人/授权音色的短歌声录音。服装附描述与季节，歌曲附来源及音色、音乐使用许可；收藏容量满或存储不可用时显示错误。
5. 在聊天里使用 `/life`、`/relationship`、`/photo selfie`、`/photo snapshot`、`/photo landscape`、`/sing 歌名`。照片需要打开“绘图”并配置图像网关；歌曲无匹配录音时不发假音频。
6. QQ 手机把图片和 `/sticker joy 笑脸` 或 `收藏表情 开心 笑脸` 一起发送；服装用 `/outfit winter 红围巾` 或 `添加衣服 冬天 红围巾`。提供的描述用于穿搭和照片提示；单发普通图片仍按既有规则处理，不冒充已理解图片。

## 机器人配置

在既有机器人配置中加入以下非秘密字段，或采用对应双下划线环境变量。保留现有 Aijade:Server、账户令牌及 OneBot 的令牌/签名密钥文件配置。不要把密钥放入示例或提交。

```json
{
  "Bridge": { "SpeakFirst": true, "Drawing": true, "StateFile": "/your/private/aijade-bots-state.json" },
  "Companion": {
    "Enabled": true,
    "NaturalPacing": true,
    "Home": "窗边的小屋",
    "City": "",
    "Latitude": null,
    "Longitude": null,
    "TimeZone": "Asia/Seoul",
    "Weather": false,
    "Appearance": "由作者填写的固定外貌",
    "Interests": "读书,音乐,做饭",
    "MusicPreferences": "轻音乐,流行音乐",
    "Friends": "书店的朋友,邻居",
    "Hairstyles": "自然披发,低马尾,半扎发"
  },
  "OneBot": { "Voice": true, "SpeakReplies": true, "TtsVoice": "alloy" }
}
```

- `Bridge:SpeakFirst` 启用私聊主动联系；`Companion:NaturalPacing` 控制 QQ 节奏。不要把不相干的群聊开放给主动消息。
- `OneBot:Voice` 是入站转写，`OneBot:SpeakReplies` 是出站真实语音，后者需要服务端 speech 路由。本机语音沿用 ADR-003 的 MOSAIC `/tts`、`/transcribe` 与对齐服务；没有服务时不产生假音频。
- QQ 自动表情从当前账号／角色的共享收藏挑选。与网页登录账号不同的机器人账号，通过网页生成的一次性码在负责人 QQ 私聊 `/bind 码` 绑定；绑定后的网页与 QQ 共用收藏。旧机器人收藏文件仍保留于 StateFile 加 `.companion` 的目录，放在仓库外的私人目录。
- 图片和歌曲会以真正的 OneBot image/record 段发送。QQ 图片只读取允许的 QQ CDN HTTPS 地址，下载不带 NapCat 令牌；宿主的 HTTP 客户端不跟随重定向。
- 未提供真实 QQ/NapCat 运行会话及音色数据，本轮不会替用户发送真实消息或启动音色训练。接通真实账号后的到达、听感与模型质量仍需实测。

## 后续补充：所有地点与音色服务均可以后再配置

作者选择“做成可以随时配置的”。现在不要求固定城市、模型或样本目录。

- **地点与时区**：陪伴生活页可查询城市，也可离线手填城市名称、时区和经纬度；可修改、清除，时区留空跟随设备。天气开启前需具备完整坐标，非法数据不会覆盖已有设置。
- **本地语音与歌声**：管理员从陪伴生活页进入“本地语音与歌声”（`/companion/services`），分别设置合成、识别、对齐、歌声的服务地址、音色标识、模型目录、授权样本目录、来源说明及健康检查路径。可先保存为停用状态，以后再启用。
- **保存效果**：服务配置保存在服务端既有配置表；每项独立合并更新，保留其他网关路由及密钥。服务后续请求读取新设置，不需要修改代码。网页地点设置保存即供两端后续回合使用；QQ 宿主原 `Companion` 配置段仅作为本人账号旧资料的一次性复制来源，绑定后以共享文档为准，无须重启。
- **状态**：保存不验证模型文件或启动训练；连接检查仅 GET 健康端点、最多等待 5 秒，显示“未配置／可连接／无法连接”，不把 HTTP 成功认定为训练完成或音色质量通过。修改地址后清除旧连接状态。
- **留空与停用**：可继续文字聊天及已有录音曲库。停用保留填写内容；管理员在该面板保存某项，会选择本地服务作为该项能力的路由，其他能力保持原配置。

### 可选本地歌声服务协议

这是 AIJADE 新增的适配协议，不代表 MOSAIC 已经提供歌声模型。已有语音服务 `/tts`、`/transcribe`、`/align` 的协议保持原样；MOSAIC 合成服务仍使用它自身已加载的固定音色。模型目录与样本目录是记录字段，不会被传给推理服务。

```text
POST {singing.upstream}/sing
Content-Type: application/json
{"song":"歌名","voice":"配置的音色标识"}

成功：200 + WAV 字节（至多 8 MiB）
未知曲目：404 或 422
```

`voice` 留空时省略该字段。本地服务可在 `GET {upstream}{healthPath}` 提供健康接口，默认路径 `/health`。AIJADE 的登录用户通过 `/api/v1/openai/v1/audio/singing` 调用适配器；返回音频格式不对或服务故障会明确失败，不把普通文字当歌声。
