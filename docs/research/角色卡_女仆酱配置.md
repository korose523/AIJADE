## 八、声线（Voice/TTS）配置指南

### 推荐声线参数

根据角色设定（年轻女性、温柔、略带俏皮），推荐以下 TTS 配置：

#### 方案 A：ElevenLabs（效果最佳）
```yaml
speech:
  provider: elevenlabs # 服务商
  model: eleven_multilingual_v2 # 多语言模型（支持中文）
  voice_id: 'Jessica' # 推荐音色：年轻女性、温暖柔和
  # 其他可选音色：
  #   "Bella"      - 年轻、活泼
  #   "Aria"       - 温柔、知性
  #   "Rachel"     - 自然、亲切
  pitch: +10% # 音高：稍高（+10% 更显年轻）
  rate: 1.05 # 语速：略快于正常（显得更有活力）
  ssml: false # SSML：暂不启用（基础模式即可）
  language: zh # 语言：中文
```

**设置路径**：设置 → 机体模块 → 发声 → 选择语音合成服务来源 → ElevenLabs → 选择声线

#### 方案 B：Kokoro TTS（本地免费，无需 API Key）
```yaml
speech:
  provider: kokoro-local # 本地 TTS 引擎
  model: fp32-webgpu # 模型精度（WebGPU 加速）
  # Kokoro 自带多个日系/二次元音色，适合本角色
  voice_id: 'af_heart' # 推荐音色（需查看实际可用列表）
  pitch: +15% # 音高偏高（更接近少女音）
  rate: 1.0 # 语速正常
```

**设置路径**：设置 → 机体模块 → 发声 → 选择语音合成服务来源 → Kokoro TTS (本地)

#### 方案 C：Microsoft Azure 语音服务（中文支持好）
```yaml
speech:
  provider: microsoft-speech # Azure 语音服务
  model: default # 使用默认模型
  voice_id: 'zh-CN-XiaoyiNeural' # 推荐音色：
  #   "zh-CN-XiaoyiNeural"   - 晓依（年轻、甜美、活泼）
  #   "zh-CN-XiaochenNeural" - 晓辰（温柔、亲切）
  #   "zh-CN-XiaohanNeural" - 晓涵（成熟、稳重）
  pitch: +10%
  rate: 1.05
  language: zh-CN
```

### 声线调节建议

| 参数 | 推荐值 | 说明 |
|------|--------|------|
| **音高 (Pitch)** | +10% ~ +20% | 稍高的音高更贴近少女声线；+30% 以上会显得不自然 |
| **语速 (Rate)** | 1.0 ~ 1.1 | 女仆角色语速适中偏快，显得更有活力；不要超过 1.2 |
| **SSML** | 可选 | 高级用户可用 SSML 精细控制停顿/重音/语调 |

### 如何在 UI 中设置声线

1. 打开 AIJADE 网页界面 (`http://localhost:5173`)
2. 点击右下角 **设置（齿轮图标）**
3. 进入 **机体模块** 分类
4. 点击 **发声** 子菜单
5. **选择语音合成服务来源**（下拉选择提供商）
6. 配置完成后点击 **选择声线**（浏览可用音色列表）
7. 点击 **播放** 按钮预览效果
8. 调节 **音高** 和 **语速** 滑块到合适位置
9. 在 **实验平台** 输入测试文本验证效果

## 九、VRM 模型配置

```yaml
# 角色卡的 VRM 扩展配置（存储在 airi-card 的 extensions.airi.modules 中）
vrm:
  source: file # 从本地文件加载
  file: 'models/vrm/meryl_maid.vrm' # VRM 文件路径（需导入）
  # 或者使用 URL：
  # source: url
  # url: "https://example.com/models/meryl_maid.vrm"

# 显示模型 ID（关联到 stage-model store）
displayModelId: 'preset-vrm-meryl'
```

### 导入 VRM 模型的步骤

1. 准备 `.vrm` 格式的 3D 模型文件（基于提供的参考图制作）
2. 打开 AIJADE → 设置 → 角色模型 → VRM
3. 点击 **从文件加载** → 选择 `.vrm` 文件
4. 模型导入后会显示在预览窗口中
5. 调整 **缩放**、**位置**、**视角** 参数
6. 在角色卡设置中将该模型关联为默认显示模型
