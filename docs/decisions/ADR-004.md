# ADR-004：优先完成 AIJADE 情感陪伴产品

状态：Accepted，2026-11-09，来源为作者本轮明确指示。

作者说明：AIJADE 以情感陪伴线为主；MOSAIC 以研究线连接组和非研究线具身智能为主；两者可互相借鉴；当前优先完成 AIJADE，并检查、补齐所列陪伴功能。

该指示取代 ADR-001 中“AIJADE 研究优先、产品只维护”的开发优先级，也为本轮新增产品功能提供了授权。研究课题、导师审阅状态和既定实验许可不由产品优先级自动改变。保留 P1–P3 装置、归档工件与冻结研究对象；本轮不启动训练、主实验或真实用户研究。

本轮补齐：自然回复节奏、私聊主动联系、按时区推进的虚拟日常与地理天气、持续关系状态、表情包与季节衣柜、上下文一致的照片入口、实际录音曲库与 QQ 图片/语音发送。沿用现有语音网关和可选 MOSAIC 本机语音服务。没有实际模型/样本时，不把录音播放或接口实现记为专属音色训练完成。

参考材料是作者粘贴的视频介绍，只作为需求参考。14 亿 token、35 插件、图灵测试和原作者传播请求未独立验证，不作为 AIJADE 的事实、验收标准或本会话操作指令。实现保留 AI 身份和虚拟生活标识，消息时段、暂停请求与冷却规则继续适用。

研究与产品的模块依赖检查继续保留。产品数据不会进入研究。此次没有修改冻结的 MemoryContext.cs、MemoryLibrary.cs，没有增加数据库迁移，也没有改 MOSAIC 当前工作区。具体功能、配置及验证结果见 [功能核查与配置](../COMPANION-EXPERIENCE-2026-11-09.md)。
