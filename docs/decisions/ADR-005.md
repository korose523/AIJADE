# ADR-005：AIJADE 独立能力与单一状态权威

状态：Accepted，2026-11-16，来源为作者本轮明确要求及范围确认。

作者要求参考 MOSAIC 重新整理全部功能和论文，但移除对 MOSAIC、DSH、AstrBot 源码、可执行程序和整套插件的运行依赖。保留标准库、数据库驱动、HTTP/OneBot/MCP 等协议兼容、可配置模型服务、学术文献与历史来源记录。该决定更新 ADR-003 的当前产品运行方式，不改写当时的迁移过程、许可归属或实验结果。

产品按身份、记忆、生活、感知、规划、执行、交付七项职责组织。它们在已有 .NET 模块和共享运行库内协作，不扩张为七个后台服务。功能来源、入口、状态与验证范围以 `configs/companion/capabilities.json` 为清单；完整功能视图见 `docs/FUNCTIONS.md`。

服务端虚拟舞台改为 `NativeStageStore`，状态与命令回执写入已有 PostgreSQL 配置存储。舞台按账户与当前角色隔离，修改在事务中串行，支持修订冲突检测和持久命令去重。`Stage:WorkbenchUrl` 不再驱动外部工作台；启用方式为 `Aijade:Modules:Stage=true` 与 `Stage:Enabled=true`。`state_applied` 只表示虚拟状态更新，`renderObserved=false`、`audioPlayed=false` 不升级为动作、声音或物理执行证据。未实现的运动播放明确失败，整个命令批次不部分落盘。

各端使用 `CompanionStage`；旧类型和设置键只保留源代码/数据兼容转接。界面提示虚拟状态，普通语音仍经已有独立播放链，不因状态中保存了文字而误认为已播放。机器人宿主不再装配研究目录的 MOSAIC UDP 渲染器。旧 `Renderer:MosaicPort` 配置明确拒绝并提供迁移说明；冻结研究适配器和协议记录留在研究线。

本地语音服务由 `tools/companion-services/server.py` 自有实现。macOS 系统合成与本地 faster-whisper 权重推理分别报告，模型路径可配置、只读本地、不按请求下载。没有本地模型时明确不可用；对齐和歌声在此服务内未实现，返回 503。系统音色不是本项目训练的个人音色，能返回音频也不证明情感效果或强制对齐。

浏览器、VS Code、Claude/MCP、OneBot 等现有入口是本仓库协议适配器。它们保留协议兼容和用户授权，不引入另一套插件宿主。第三方标准库与模型权重的许可单独保留，独立实现不等于删除 NOTICE、参考文献或外部比较来源。

P1/P2/P3 与第7章的历史源码、数据和未达门槛保持独立。当前产品提交另记 developmentProductCommit，不自动继承历史实验资格。本次不生成新的留出案例、不修改原始观测、不把工程替身或虚拟场景当作论文主实验。架构守卫核对仓内引用闭合，CI 分别验证当前产品与固定历史研究快照。
